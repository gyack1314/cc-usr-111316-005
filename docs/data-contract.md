# 边际状态与关联约束

states位置在源表有意义；合并同值时须更新事件状态引用并保留原位置。event中各维允许状态集合取交集，未列维不限；moment_constraints给显式格点系数或登记矩函数，只线性作用于联合概率。所有约束闭区间。

可信函数登记sum-loss，以及aggregate-cover：先各灾害扣免赔并截各自上限，再把和截共享上限；参数由调用方传值，不能执行代码字符串。thresholds用严格大于，不含阈值点。每阈值有独立原始及对偶解。默认示例两个维度，边际完全不约束关联。

预算是终止资源，并非概率界。初始模块只核验维度身份和状态形状，不构造运输表或执行优化。

## 锐界求解口径（analysis_data.bounds / lpsolve）

- 联合格点概率为未知量，约束只含登记的边际、事件闭区间与线性矩；未登记关联不自行补齐，独立性绝不作为隐含假设。
- 对每个阈值分别求 P(total>t)（严格）与 P(total>=t)（含阈值点）的最小/最大；不同阈值的极值可来自不同关联结构，各自标注极值分布，互不联立。仅当调用方明确要求共同分布的多阈值目标时才联立（默认不启用）。
- 每个界同时给：达到它的稀疏联合分布（含各维原始状态位置，便于查看哪些灾害年份配到一起）、原约束残差、可独立复算的对偶证书（弱对偶+强对偶相等）。全部用 Fraction 精确有理算术，不使用浮点近似。
- 资料相互矛盾时给 Farkas 不可行证据（统一为"左式>=0"的非负组合，常数项<0）。枢轴/状态预算耗尽时只报当前可行界（西北角耦合）与证书间隙，状态标 gap，绝不标锐界。
- 格点超过 solver_budget.max_states 时启用列生成；定价子问题枚举整个笛卡尔格点（全局有效），不用随机抽样。列生成结果与全枚举在测试中逐值核对一致。
- LP 引擎为纯标准库两阶段单纯形（Bland 规则防循环），无第三方依赖。
- 独立性乘积测度、共同分位耦合、调用方给定的真实联合表仅作参照并显式标注假设，落在可行域界内但不替代上下界。
- 格点费用缓存绑定合同名+参数、合并后状态、阈值与严格/非严格口径，键不匹配即不命中。
